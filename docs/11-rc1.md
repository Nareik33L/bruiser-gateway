# Bruiser Gateway — RC1

V1 stays feature-frozen. RC1 closes the independent security review.
The product promise is unchanged: **one customer, one execution.**

## Release notes

Production Candidate (RC1) hardens identity, origin authority, resource
identity, fencing, merchant execution budget, session revocation, replay,
authorize least privilege, rate limits, and the header trust boundary.
No commercial features were added.

### Closed findings

| ID | Finding | Closeout |
|----|---------|----------|
| C1 | Production identity | JWKS/OIDC with issuer, audience, expiry, merchant binding, rotation, fail-closed cache. `BRUISER_ENV` must be `lab` or `production`. HS256 only when `BRUISER_ENV=lab` and `BRUISER_DEV_ASSERTIONS=1`. Empty env is not lab. |
| C2 | Origin authority | Origin secret is path trust only. Allocation requires a valid Bruiser execution JWT + fence + merchant + canonical resource + expiry; revoke via introspect. Verification is on unless lab-only `AllowOriginSecretOnly`. Garbage token + valid origin secret is 403. `/v1/authorize` never returns the origin secret. Authority Check sends a valid secret with a forged token and expects 401/403. |
| H1 | Canonical resource | NFKC + dash/space/quote folding, strip leading/trailing non-alnum, collapse separators to `:`, then `[a-z0-9:-]` allowlist and `type:ident`. Optional merchant `resources:` catalogue resolves the folded ID or rejects (`ErrUnknownResource`). Domain keys go through `Canonical()`. |
| H2 | End-to-end fence | Downstream SDK + origin + introspect reject stale fence, revoked, and handed-off executions. Origin verification is fail-closed; `AllowOriginSecretOnly` is lab-only. |
| H3 | Execution budget | Merchant policy `budget.max_ops` (omit or 0 = unlimited). The drop-in example ships `max_ops: 1` to match one-seat behaviour. |
| M1 | Session revocation | `POST /v1/sessions/logout` and `/revoke`. Authenticated routes check the session store. Refresh issues a new token only for a live session. |
| M2 | Replay | `Idempotency-Key` / `X-Bruiser-Nonce` / client `X-Request-Id` recorded; duplicates return 409. |
| M3 | Secure authorize | Edge secret required. Response is execution material only. Every ALLOW is audited. |
| M4 | Rate limits | Configurable per sessions/acquire/renew/release/authorize and merchant/customer/principal/IP. `bruiser_rate_limited_total`. |
| M5 | Header trust | Inbound `X-Bruiser-*` stripped except edge/admin/event. Production rejects `extractor: auto` plus an unsigned customer header unless `identity.allow_unsigned_header: true`. |
| L1 | Control surface | Revoke/handoff/JWKS/Embedded SDK exist. Admin RBAC remains a single admin secret in RC1 (documented; SSO is post-RC1). |
| L2 | Clock skew | 5s leeway on `exp` only. Fence comparison has no skew. |
| L3 | State terms | Decision: `ALLOW`/`BUSY`/`QUEUED`/`DENIED`. Execution: `ACTIVE`/`RELEASED`/`EXPIRED`/`REVOKED`/`HANDED_OFF`/`QUEUED`. Advertised on `/.well-known/bruiser/protocol`. |

## Authority Check

`bruiser authority-check --front <edge> --origin <origin> --control <bruiser>`
must be **PASS** before go-live. The check proves the authority chain:
customer identity → Bruiser admission → execution JWT/fence → origin
verification → inventory. Probes send a **valid origin secret** with a
forged, modified-fence, expired, revoked, wrong-resource, or
wrong-merchant execution and expect 401/403, never 2xx. Cosmetic
resource variants (trailing `. - _ ! @`, Unicode hyphens) fold onto
one domain; an extra colon (`event:ars:che`) is still rejected.

Lab: `make authority-check` against Compose.

## Configuration validation

`bruiser config validate` prints `PASS` / `FAIL` with an actionable field
for: missing `BRUISER_ENV`, default secrets, missing JWKS (production),
invalid issuer/audience, missing origin lockdown, unsafe unmatched routes,
duplicate secrets, invalid mode, HMAC assertions outside `lab`,
`extractor: auto` plus unsigned header in production.

Lab (`BRUISER_ENV=lab`) against `configs/example.yaml` is PASS with WARN on
`unmatched: allow` and empty `resources:` catalogue. Production
(`BRUISER_ENV=production`) FAILs that file until JWKS/issuer/audience,
generated secrets, and an explicit identity opt-in (or oidc without an
unsigned header) are set.

renew/reconnect/release/queue, replica kill at 12m + replacement at

about 12% lower (LiveSession + keyed rate-limit checks on the hot

are at or better than that baseline. Not a material health regression.
